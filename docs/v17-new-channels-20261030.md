## 1. Good Design Tools — ID 147（P1，设计相关性最强）

- 官网：[gooddesign.tools](https://www.gooddesign.tools/)；[Typography 的真实条目：Type Trials](https://www.gooddesign.tools/tools/type-trials)。
- **提交入口：[官网引用的 Tally 表单](https://tally.so/r/mBbA8N)**。此链接由该站公开页面的“Submit a tool”跳转得到，表单在本轮可打开。
- 免费资格：第三方2026-09-15核查称免费、免账号、不强制回链；尚未获得站方对纯西语产品的明确承诺。
- 可核验公开样例：`/tools/type-trials` 是 Typography 资料页，有“View site”指向工具网站。
- 权重：第三方在2026-09-15称 Ahrefs DR 25，抽样60个页面发现直接普通出站链接。**不作为本站独立DR或新提交页Follow实测。**
- 需要填写：工具名、实际主页URL、英文短简介（第三方称 ≤130字符）、定价类型 Free、图标（第三方称方形 JPG/JPEG/WEBP/SVG；不要直接用PNG，按表单当前规则）、邮箱。
- 网站拟用名：`Generador de Lettering`；建议分类：`Typography` 或 `Design Software`（以实际表单可选类别为准）。
- 英文短介绍：`Free Spanish lettering editor with customizable text styles, colours and PNG/JPG/WEBP image exports. No signup.`
- 申请后：保存成功提示，编辑确认后记录最终详情页URL；核验是否有正确 `href`、`rel` 及 `robots`。

**关键风险：** 优质设计目录不等于一定认可西语站，也不保证录取、索引或实际引荐流量。第三方调查不能代替亲自审核新页面。

## 2. NoSignupTools — ID 148（P1，功能类型匹配）

- **提交：[NoSignupTools submit](https://nosignuptools.com/submit)**；[已公开的字体类案例 FontsWiki](https://nosignuptools.com/tools/fontswiki)。
- 官网要求：**核心工具无需注册且真正免费**；网站必须公开可访问，正常工作，无恶意或垃圾内容。
- 官网审核目标：约24–48小时，**不是审批保证**。
- 表单字段：Tool Name、Tool URL、Tool Icon（方形建议，不超过1MB）、Category（选 Design）、Short Description、Detailed Description、Screenshots（最多6张，每张不超过2MB）、相关标签（例如 Multi Language、Mobile Friendly，必须符合事实）、可选姓名与邮箱。
- 中文填写原则：不要笼统声称“拥有全部商业字体版权”；描述为浏览器字体/字形排版编辑器，正确说明设计与导出功能。
- 英文短介绍：`Free Spanish lettering editor. Create decorative text, adjust colours and effects, and export PNG, JPG or WEBP without signing up.`
- 详细介绍：`Generador de Lettering is a free browser-based lettering editor in Spanish. Users can customize decorative text, adjust style, colour and effects, and export their compositions as PNG, JPG or WEBP images. Core features work without creating an account.`
- 不要标记 `No Ads`（目标网站可能显示 AdSense 广告）；勾选 `Mobile Friendly` 前先用手机检查。

**链接证据级别：** 官网页面确有指向 FontsWiki 官网的外链，但目标新条目 `rel`、DR、可索引性仍未实测。

## 3. PeplioHUB — ID 149（P1，免费工具社区）

- **提交：[PeplioHUB 免费工具发布](https://peplio.com/pepliohub/#submit-tool)**；[官方规则](https://peplio.com/pepliohub/rules/)。
- 官网表示：免费、提交无需先登录、手工/自动质量筛查，公开单独详情页和网站链接；有 `Design and images` 分类。
- 需要填写：网站URL→确认自动填充→名称、分类、Tagline（≤80字符）、详细说明、Free、Web app→**真实主图至少1200×675（16:9，必须）**，Logo可选、最多3张附图→提交者姓名和邮箱。
- 英文短介绍：`Make decorative Spanish lettering online for free. Customize text and export images.`
- 英文产品介绍：`Generador de Lettering is a free, no-signup lettering editor for Spanish-speaking creators. Customize text styles, colours and effects in the browser, then export finished designs as PNG, JPG or WEBP.`
- 官方规则允许平台以后将外链标记改为 `nofollow` 或 `ugc`，不承诺永久Follow。
- 官网表示徽章只影响 Badge partner 识别/可能提前展示，不以互换链接为条件。**不要为了 SEO 安装回链徽章、刷票或互换链接。**

**质量结论：** 收录价值可能在工具曝光与实际访问，Follow/DR/索引状态都以审核后的自身详情页为准。

## 4. HereIsMySaaS — ID 150（条件，不列 Lettering 优先）

- [官网资格与链接声明](https://hereismysaas.com/why-be-listed)；[提交入口](https://hereismysaas.com/submit)（本轮访问需先登录）。
- 官网声称免费人工审核、可得到普通外链、不强制徽章；另有付费推广，不必购买。
- **限制：只面向 indie SaaS**。普通免费字体编辑器能否被定义为 SaaS 并接受，目前没有站方的确认。
- 仅当某个项目确实是独立 SaaS 产品（而非普通内容流量站）时考虑填写产品链接、英文一句话介绍和真实分类。
- 官网的 Follow 描述并不等同于对本次目标页面的独立 DOM 核验；DR/AS 未测。

## 本轮排除：Tool Index（非新增主优先队列）

[Tool Index 的设计工具提交说明](https://toolindex.net/submit-your-tool/design-tool) 明确：所谓免费收录要求申请者在自己网站放一个返回 Tool Index 的 `nofollow` 链接；不放回链的提交走付费档。按照“除域名外尽量零成本、尽量不修改既有高流量首页”的标准，本轮不建议优先申请，避免把“免费”误解为“无附加义务”。
