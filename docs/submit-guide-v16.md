## 二、这轮新增的6条，按实际价值排序

### 1. GainWeb — 有明确免费表单，条件补充

- **入口：** https://gainweb.org/submit.php
- **官网确认：** `Regular — Free`，但 `No Guarantee of Review or Approval`。付费 `$25/$45` 是优先审核/展示，不需要购买。页面真实包含标题、网址、分类、Owner Email 等字段。
- **适合网站：**设计、软件、计算器及普通内容网站。分类树里存在 `Computers and Internet → Design and Graphics`，但西语网站能否通过最终审核**没有明确语言保证**。
- **按照页面操作：**
  1. 检索站名和根域名，排除重复申请。
  2. 打开上方网址，选择 `Regular - Free`，不要选择付费套餐。
  3. Title 填 `Generador de Lettering`；URL填 `https://generadordelettering.org/`。
  4. Category 选最贴近的设计或软件类别；Description 用下方准确的英文介绍；Owner Email 填实际可接收邮件的邮箱。
  5. 不虚构所在地、电话或机构资质，同意规则后提交并记录确认。
- **已核实：**网站存在公开 `Latest Submissions`，例如 https://gainweb.org/latest-links.html ，但**样例rel、当前DR和实际引荐量均未核实**。
- **价值判断：**填表成本较低，值得放入“条件补充”，不能列为高DR优先站。
- **来源：** https://gainweb.org/submit.php ；https://gainweb.org/rules.php

### 2. Cipinet — 可免费提交，但预计审核4–5个月

- **入口：** https://www.cipinet.com/suggest.php?TID=sf&action=addlink
- **官网明确限制：**只允许主域名，不收子域名和内部页；免费条目排在收费项目之后；审核大约4–5个月。
- **填写步骤：**Category → URL → Site Title → Description（不超过200字符）→ E-mail → 验证码 → Submit。对于 Lettering 站，提交主域名，而不是 `/font-generator` 等内页。
- **适用性：**纯西语资格未得到明确书面确认。作为一次性、低时间成本的备选，不应计入短期获链计划。
- **DR/AS和最终Follow属性：**未实测。
- **来源：** https://www.cipinet.com/suggest.php?TID=sf&action=addlink

### 3. Gimpsy — 虽称普通Follow，但纯西语网站不符合规则

- **入口与规则：**https://gimpsy.com/plan
- **官方明确：**只收真正具有在线交互功能的网站；主要接受英文网站，或英语功能与其他语言一样完整的多语网站。
- **费用与审核：**可免费建议网站，但官网当前说明免费审核队列约**14个月**；`$9/$29/$49` 属于加速/推广服务。
- **链接属性：**官方声称目录使用普通外链、非 `nofollow`/`ugc`/`sponsored`。这是**平台自述**，并非对你的未来页面的独立核验。
- **结论：**只运营纯西语功能的 Lettering 站不应申请；如果未来另一个网站确实提供完整英文功能，再按实际规则判断。不能为了获链虚构一个英语页面。
- **来源：**https://gimpsy.com/plan

## 四、通用的可复制填写文案

### 用于西语目录

**短描述（适合170字以内字段）：**

**较长描述：**

> Generador de Lettering permite transformar texto en estilos Unicode para copiar y pegar, además de crear composiciones de lettering desde el navegador y exportar diseños en formatos de imagen. Es gratuito y se puede utilizar sin instalar programas.

### 用于允许西语产品但要求英文介绍的发布站

**Product name：** `Generador de Lettering`

**Tagline：** `Free lettering designer and copy-and-paste text styles`

**Long description：**

> Generador de Lettering is a free Spanish-language browser tool for decorative text. Visitors can explore Unicode text styles, copy styled text, create lettering compositions, and export designs as images without installing software.

**Category：** `Creator Tools`（可选时），否则选页面提供的最贴近实际功能的分类。

**Why did you build this：**（仅当该动机属实才填）

> We built this tool to make decorative typography easier to explore for Spanish-speaking creators, students, and anyone who needs quick lettering designs without design software.

**注意：**英文提交资料不等于网站具有英文版本。不能用英语介绍冒充有完整英语功能，以绕过Gimpsy的语言要求；不能冒称AI、下载安装字体、无广告、已拥有用户数量等未经核实的特点。

## 五、以后每个新西语网站如何操作

1. 将**项目主域名**规范化：例如 `https://generadordelettering.org/`；同一“目标根域名 × 提交平台根域名”只建立一个基础提交记录。
2. 从V16《优先行动清单》选**真正符合网站类别和语言条件**的平台。
3. 用实际功能写原创描述，必要时提供完整英文解释，但不要编造英文UI或收入数据。
4. 保存提交日期、邮箱（不保存密码）、所选类别、审核确认、最终公开条目URL。
5. 条目上线后，独立检查：页面HTTP状态、canonical、robots/index规则、真正指向你网站的`href`、链接`rel`属性、实际可索引性和真实引荐访问。
6. 审核没有通过或没有公开页面，就不能算获得外链。不要重复提交、交换大量回链、购买声称“保证排名”的Follow服务。

Google Search Central明确将**低质量目录链接、为操纵排名而批量制造链接**列为链接垃圾信息示例，因此应以真实有用的推荐为目标，而不是堆砌外链数量。官方规则：https://developers.google.com/search/docs/essentials/spam-policies
