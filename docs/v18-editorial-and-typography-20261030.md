## 三、编辑推荐——按真正适配的内容而非泛化SEO投稿

### A. EDUCACIÓN 3.0——教材价值较强，但已接触同编辑部其他项目

- 与主题相符文章：https://www.educaciontrespuntocero.com/recursos/ejercicios-para-repasar-caligrafia/
- 官网联系：https://www.educaciontrespuntocero.com/contacto/ 。编辑邮箱由官方公布：`redaccion@educaciontrespuntocero.com`
- 可贡献素材：https://generadordelettering.org/herramientas/plantillas-practica ，**4套A4 SVG：笔画、小写、大写、花饰/连接**；另有七日练习方案：https://generadordelettering.org/blog/plan-practica-lettering-siete-dias
- **不同于一般字体转换器**：教育内容必须以实际练习、打印规格和使用限制为主；不能声称产生PDF文件或具备自动教学评价。
- **查重结果**：2026-10-12 已向该编辑部寄过 `numerosenletras.org` 数字文字练习资源，因此不要仅为凑外链频繁重复推送；若未来有新的独立课堂使用案例再联系。

建议提供的编辑价值：一页示范教案（10分钟热身，打印A4，观察书写间距、倾斜和笔画），附原创 SVG 实例与可追溯页面。**是否引用完全由编辑决定。**

### B. Gràffica——设计相关性高，但 Lettering 介绍已经发送

- 主题文章：https://graffica.info/curacion-tipografica-el-mapa-del-tesoro/
- 官方联络页：https://graffica.info/contacto-2/ （其 `prensa@graffica.info` 是新闻稿通道，不是免费外链提交表单）
- **邮箱查重已确认**：2026-10-25 实际已发送标题 `Recurso gratuito en español para crear lettering digital`。邮件已介绍在线编辑器及SVG练习材料。
- 因此**不要再发相同首轮邮件**。在没有新的产品研究、原创可展示设计、案例或编辑主动征询时，维持“已发送，等待是否有真实反馈”。
- 若后续有真正独立的新闻价值，可提供原创比较研究：浏览器Lettering图像编辑与Unicode可复制文字的差异（可用性、导出、可访问性），附事实可复现的截图与版权清楚的素材，而不是请求“给个 dofollow 链接”。

### C. Domestika——联系入口存在，但不是编辑投稿表单

## 四、提升新闻价值：目前已有可复用的实际产品素材

Generador de Lettering 目前网站真实公开功能包括：

1. 视觉排版与编辑器：`https://generadordelettering.org/editor`；支持色彩、轮廓/阴影和 PNG/JPG/WEBP 图片导出。
2. Unicode文字转换：`https://generadordelettering.org/herramientas`；功能不同于“真正字库文件TTF/OTF”，**不得混淆**。
3. 练习模板：`https://generadordelettering.org/herramientas/plantillas-practica`；A4 SVG，4类练习指导；实际打印比例因设备不同可能有变化。
4. 七日练习方案：`https://generadordelettering.org/blog/plan-practica-lettering-siete-dias`；可以作为教学内容的前期材料，而不是声称“保证掌握Lettering”。

**编辑推荐的关键不是高权重站愿不愿意交换链接，而是有没有对它们的现有读者有独立价值、可复用和可核实的资源。**

## 五、获链验收与维护

- 候选 / 已发送联系 / 编辑回复 / 审核通过 / 公开页面 / 公开正确出站URL / rel / 索引 / 引荐会话为不同状态。
- `data/backlinks-master.csv` 仅放标准化提交渠道；`data/editorial-prospects.csv` 是编辑选题与联系人研究；`data/editorial-outreach-ledger.csv` 是真实对外接触记录；`data/submission-ledger.csv` 是目录类实际提交台账。
- **不强制回链、不买低质目录、不群发相同模板、不伪造编辑身份、不给付费赞助写成免费编辑推荐**。
- 不在GitHub保存邮件账号密码、内部联系人私密数据或Token；已写入的编辑邮箱来自公开官网。
- 每次修改后运行 `python3 scripts/validate_csv.py`，并检查GitHub Actions实际成功状态。
