# V30｜真正可跨站复用的176渠道外链操作台 + 本地进度安全备份

核对日期：2026-10-31。原主库 `data/backlinks-master.csv` 仍为**176条历史渠道**；正式记录 `data/submission-ledger.csv` **本次未修改**。本次没有申请目录、发送邮件、安装互链徽章或取得确认反链。

## 1. 核心问题修复：切换新网站后，21家精细填写卡真正可使用

V29对21家平台已提供133行原始字段，但切换到其他西语网站后很多旧字体介绍会被标成不可复制。V30将每个字段与用户顶部**主动编辑**的站点资料绑定：

- **站名 / URL / 邮箱**：只有用户提供真实名称、同域工具页和邮箱才允许复用，不从旧网站借用错误目标网址。
- **英文短文案、详细说明、西语短文案、详细说明**：如果用户为新站主动更新过顶部资料，才允许在对应英文、西语Description字段复制。若仍是Generador预填的旧内容，显示`【请先在顶部填写新网站的真实……】`，禁用该字段复制按钮。
- **分类 / 定价 / 国家 / 职位 / 作者 / 标签 / 验证码 / 隐私承诺**：不能从其他网站的填写值推定当前网站的情况，必须手工根据真实业务和当日平台官网选择，不提供虚假一键复制。
- **具体教学页**：只给Generador使用其真实Lettering练习页，新网站需要真实教学资源URL，不再拼接不存在的路径。
- **域名切换**：自动清空此前其他域名的工具页URL，避免错投。仅把实际提交进度隔离到网站域名，不会跨网站借用“已提交”记录。

**注意**：这些是编辑资料的辅助操作，不对外提交，不代表平台已审核通过或取得Follow。

## 2. 备份和恢复：可以从一台Windows Chrome转移到另一台

V30离线HTML新增两个按钮：

1. **备份所有网站JSON**：下载`spanish-backlinks-progress-backup.json`，包含操作台当前站点的资料、所有已保存网站的本地阶段和备注；无需联网/付费账号。
2. **恢复进度备份**：由用户在本机手动选择以上JSON文件，程序先严格检查版本、站点域名、渠道编号1–176、进度状态、文件大小和备注长度，再征求明确的覆盖确认，最后恢复到当前浏览器。

**隐私与备份提示**：JSON包含你自己填写的联系邮箱、个人备注甚至可能有其他联系信息。它是个人本地备份，**不要提交到公开GitHub仓库**；不要在备注放密码、邮箱登录Token或API Key。浏览器清理站点数据可能清空本机记录，定期自行下载JSON很重要。

旧有CSV导出仍保留，下载文件名含**当前目标网站域名**，避免混淆多站。V30也对CSV字段加了电子表格公式注入防护：备注或任意字段以`=`、`+`、`-`、`@`开头时，导出文本前加单引号，减少Excel直接打开执行公式的风险。CSV仅表示**你本地记录的进度**，不会声明独立核实获得了高DR反链。

## 4. GitHub Actions当前红灯的事实边界

最近GitHub Actions仍出现红灯。此前**无需checkout/源码/脚本的最小runner-probe也失败**，切换Runner映像后仍失败，且GitHub连接器读Job日志返回BlobNotFound。无法据此唯一确定是账号额度、Runner启动分配或平台问题。**仓库保留有效校验步骤，未为了获取绿色徽章删除检查，也不声称本轮CI通过**。本地独立检查/模拟通过不等于GitHub Actions成功。

如要进行GitHub端问题定位，应在仓库 Actions 中点开实际失败作业，查看`Set up job`旁的可读错误或账户用量/结算提示，待服务恢复后再执行完整校验。
