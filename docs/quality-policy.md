# 外链质量与验收规范

## 口径

- **KD** 是关键词竞争难度，不是域名权威度。审查外链应记录 DR（Ahrefs）、AS（Semrush）、DA（Moz），并且每项写明工具、日期和来源。
- 第三方历史 DR / Follow 抽样不能当作目标产品页实时认证，更不能当作获链成功。
- **提交 ≠ 审核通过 ≠ 公开获链 ≠ Google 已索引 ≠ 实际 SEO 收益。** 这五种状态要分开。
- 不因为 Follow 或 DR 数字好看就忽略主题相关性、垃圾内容、流量、审核等待与站点信誉。

## 渠道状态

- `P1`：候选优先级，不代表通过全部质量核验。
- `P2`：一般候选，适用性较窄或实际价值偏低。
- `条件`：有语言、内容类型、回链徽章、无广告、登录、实体企业或其他门槛。
- `待核验`：入口/费用/权限等不明，先查证再操作。
- `排除`：收费、无效、与业务不符、垃圾目录或规则不允许。
- `非外链`：仅提供索引提交等服务，不计为反向链接。

## 逐站验收清单

1. **资格**：允许纯西语吗？目标工具类型是否受理？是否允许广告？免费渠道是否仍开放？有无强制徽章/回链？
2. **真实提交**：直接入口是否能打开？是否收到邮件、后台状态或提交确认？是否重复提交？
3. **公开页面**：给出能在未登录状态访问的永久 URL；核对其 `canonical` 与 `robots`。
4. **准确链接**：检查公开页面是否存在指向目标站规范网址的 HTML `a href`，是否有跳转、`rel="nofollow"`、`ugc`、`sponsored` 等属性。
5. **可索引性**：不能仅根据页面内 `index,follow` 就宣称 Google 已索引；需要有独立索引证据。
6. **价值**：记录页面主题、是否真实有人访问、引荐会话、搜索流量变化；不要从一次收录推断排名改善。
7. **持续复核**：删除、跳转、改为付费或更改 rel 后更新状态和核验日期。

## 禁止或避免

- 不购买 PBN、垃圾链接套餐、伪装编辑推荐、刷投票和批量目录灌水。
- 不为获取所谓 Follow 擅自改动已有流量站的首页、广告配置或安装长期徽章。
- 不用相同模板大量发表评论，不把评论区 URL 当高质量外链。
- 不向要求实体所在地或英语完整版本的平台提交不符合条件的纯西语工具站。
- 不保存网站密码、邮件密码、OAuth token 等秘密。

## 每次新增必须记录

平台名、注册根域名、语言要求、适合类型、真实提交入口、是否收费、强制回链条件、官方依据 URL、核验日期、链接属性证据、DR/AS 实测的来源及日期、目标站点、提交结果。

**跨站去重键**：`目标站点根域名 + 外链平台注册根域名`。同平台适配不同自有网站可分别申请，但不可对同一网站反复提交。

## V16 仍未解决的事实空缺

2026-10-30 的 V16 是候选库，不是已获链数据库。历史146条的 DR/AS 并未全部独立实测，免费档真实 rel、Google 索引状态及实际引荐流量仍有大量缺口。
